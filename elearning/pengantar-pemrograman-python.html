01

Apa itu Python?

Kenali bahasa pemrograman yang mengubah industri teknologi dunia

Python adalah bahasa pemrograman tingkat tinggi yang diciptakan oleh Guido van Rossum dan pertama kali dirilis pada tahun 1991. Python dirancang dengan filosofi utama: kode harus mudah dibaca dan ditulis, hampir seperti membaca bahasa Inggris biasa.

💡
Mengapa Python?

Pada 2024, Python menempati posisi #1 dalam indeks popularitas bahasa pemrograman TIOBE — mengalahkan Java dan C. Python digunakan di hampir semua bidang: web, data science, AI, otomasi, hingga riset ilmiah.

Keunggulan Python

📖

Mudah Dibaca

Sintaks Python bersih dan minimalis. Tidak ada tanda kurung kurawal atau titik koma yang membebani seperti di bahasa lain.

🚀

Cepat Dikembangkan

Kode Python biasanya 3–5× lebih pendek dibanding Java atau C++, sehingga produktivitas pengembang meningkat drastis.

📦

Ekosistem Luas

Lebih dari 450.000 paket tersedia di PyPI — dari web framework hingga library machine learning seperti TensorFlow dan scikit-learn.

🌐

Multi-Platform

Jalankan kode Python yang sama di Windows, macOS, maupun Linux tanpa perubahan apapun.

Python Digunakan di Mana?

  • Web Development — Django, Flask, FastAPI
  • Data Science & Analitik — Pandas, NumPy, Matplotlib
  • Kecerdasan Buatan & ML — TensorFlow, PyTorch, scikit-learn
  • Otomasi & Scripting — automasi tugas berulang, bot
  • Keamanan Siber — penetration testing, forensik digital
  • Riset Ilmiah — komputasi numerik, simulasi
02

Sintaks Dasar Python

Blok bangunan pertama yang harus kamu kuasai

Berbeda dengan bahasa seperti Java atau C++, Python tidak menggunakan tanda kurung kurawal {} untuk menentukan blok kode. Sebagai gantinya, Python menggunakan indentasi (spasi/tab) yang konsisten.

Hello, World!

Program pertama yang selalu ditulis saat belajar bahasa baru:

Python 
# Ini adalah komentar — diabaikan oleh Python
print("Hello, World!")
print("Selamat datang di Python!")

Komentar

Komentar diawali dengan tanda # dan tidak akan dieksekusi:

Python 
# Komentar satu baris

"""
Ini adalah komentar
multi-baris menggunakan
triple quotes
"""

nama = "APTIKOM"  # komentar di akhir baris juga bisa

Input dari Pengguna

Python 
nama = input("Masukkan namamu: ")
print(f"Halo, {nama}! Selamat belajar Python.")
Tips

Gunakan f-string (format string) seperti f"Halo, {nama}" untuk menyisipkan nilai variabel ke dalam teks. Ini cara modern dan paling direkomendasikan di Python 3.6+.

03

Tipe Data & Variabel

Cara Python menyimpan dan mengolah informasi

Variabel di Python bersifat dinamis — kamu tidak perlu mendeklarasikan tipe data secara eksplisit. Python akan secara otomatis mendeteksi tipe berdasarkan nilai yang diberikan.

Tipe Data Utama

Tipe Nama Contoh Deskripsi
int Integer 42, -7, 0 Bilangan bulat
float Float 3.14, -0.5 Bilangan desimal
str String "Python" Teks/karakter
bool Boolean True, False Nilai logika
list List [1, 2, 3] Kumpulan data terurut
dict Dictionary {"key": "val"} Pasangan kunci-nilai

Contoh Deklarasi Variabel

Python 
# Bilangan
umur = 20
ipk  = 3.75

# Teks
nama      = "Andi Pratama"
universitas = 'USU Medan'

# Boolean
aktif  = True
lulus  = False

# List (seperti array)
mata_kuliah = ["Algoritma", "Basis Data", "Jaringan"]

# Dictionary (key-value)
mahasiswa = {
    "nama": "Andi",
    "nim":  "21010001",
    "ipk":  3.75
}

# Cek tipe data
print(type(umur))       # <class 'int'>
print(type(nama))        # <class 'str'>

Operasi pada String

Python 
teks = "Belajar Python di APTIKOM"

print(teks.upper())      # BELAJAR PYTHON DI APTIKOM
print(teks.lower())      # belajar python di aptikom
print(teks.split())      # ['Belajar', 'Python', 'di', 'APTIKOM']
print(len(teks))          # 25 (jumlah karakter)
print(teks[8:14])         # Python (slicing)
04

Kontrol Alur

Buat program yang bisa mengambil keputusan dan mengulang tugas

Percabangan — if / elif / else

Digunakan untuk mengeksekusi blok kode tertentu berdasarkan kondisi:

Python 
nilai = 78

if nilai >= 90:
    print("Grade A — Sangat Baik")
elif nilai >= 80:
    print("Grade B — Baik")
elif nilai >= 70:
    print("Grade C — Cukup")
else:
    print("Grade D — Perlu Perbaikan")

# Output: Grade C — Cukup

Perulangan — for Loop

Iterasi atas urutan data seperti list, string, atau range:

Python 
# Iterasi atas list
buah = ["apel", "mangga", "jeruk"]
for item in buah:
    print(f"Saya suka {item}")

# Iterasi angka 1–5
for i in range(1, 6):
    print(f"Angka ke-{i}: {i * i}")  # cetak kuadrat

Perulangan — while Loop

Python 
hitung = 1

while hitung <= 5:
    print(f"Hitungan: {hitung}")
    hitung += 1  # jangan lupa update, atau infinite loop!

print("Selesai!")
Perhatian

Pastikan kondisi while akan menjadi False pada suatu titik. Jika tidak, program akan berjalan terus tanpa henti (infinite loop) dan perlu dihentikan secara paksa dengan Ctrl+C.

break dan continue

Python 
for i in range(10):
    if i == 5:
        break       # keluar dari loop saat i=5
    if i % 2 == 0:
        continue    # lewati iterasi ini (angka genap)
    print(i)        # hanya cetak 1, 3
05

Fungsi (Function)

Kemas logika menjadi blok kode yang bisa dipakai ulang

Fungsi adalah blok kode yang diberi nama dan dapat dipanggil berkali-kali. Ini adalah prinsip DRY — Don't Repeat Yourself. Daripada menulis kode yang sama di banyak tempat, cukup buat fungsi dan panggil saat dibutuhkan.

Mendefinisikan & Memanggil Fungsi

Python 
# Mendefinisikan fungsi
def luas_persegi_panjang(panjang, lebar):
    luas = panjang * lebar
    return luas

# Memanggil fungsi
hasil = luas_persegi_panjang(10, 5)
print(f"Luas: {hasil} cm²")   # Luas: 50 cm²

# Fungsi tanpa return (prosedur)
def sapa_mahasiswa(nama, prodi):
    print(f"Halo {nama} dari prodi {prodi}!")

sapa_mahasiswa("Budi", "Informatika")

Parameter Default

Python 
def buat_profil(nama, kota="Medan", role="Mahasiswa"):
    print(f"{nama} | {kota} | {role}")

buat_profil("Citra")
# Output: Citra | Medan | Mahasiswa

buat_profil("Dimas", "Jakarta", "Dosen")
# Output: Dimas | Jakarta | Dosen

Lambda — Fungsi Anonim

Python 
# Lambda: fungsi singkat satu baris
kuadrat = lambda x: x ** 2
print(kuadrat(7))   # 49

# Lambda di dalam sorted()
mahasiswa = [
    {"nama": "Andi", "ipk": 3.5},
    {"nama": "Budi", "ipk": 3.8},
    {"nama": "Citra", "ipk": 3.2},
]
urut = sorted(mahasiswa, key=lambda m: m["ipk"], reverse=True)
print(urut[0]["nama"])  # Budi (IPK tertinggi)

Tantangan Koding

Tuliskan sebuah fungsi Python bernama hitung_rata yang menerima sebuah list angka dan mengembalikan nilai rata-ratanya. Uji dengan list [80, 90, 75, 85, 95].

Lihat Petunjuk 
def hitung_rata(angka):
    total = sum(angka)
    rata  = total / len(angka)
    return rata

nilai = [80, 90, 75, 85, 95]
print(f"Rata-rata: {hitung_rata(nilai)}")  # 85.0
